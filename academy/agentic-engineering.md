outcomes:
  heading: By the end you can run a software project with agents, and answer for the result.
  items:
  - Turn a product idea into a spec and a set of small tasks.
  - Build a full-stack feature across the interface, the API and the database.
  - 'Work in an existing codebase: debug it and review agent-generated changes.'
  - Automate tests and releases with CI/CD.
  - Deploy your application and use logs and metrics to investigate failures.
  - Connect agents to tools through MCP and build reusable workflows for implementation and code review.
  - Run multiple coding agents in parallel on a backlog with automated checks.
  - Work with spec-driven development, loop engineering and graph engineering.
  - 'Take an idea to production: specs, a local version, deployment, CI/CD, production readiness and monitoring.'
  - Set up an agent that fixes things live when they break.
  - Define agent roles like product manager, software engineer and QA engineer, and the process between them.
  - Network, find projects to solve and build your portfolio, with mock interviews. The program spends 2 to 3 weeks on this.
project: You ship a working web application for a real user task. People try it, you improve it from their feedback, and you show how you tested and released each change.
fit_first: You write code today (Python, JavaScript, TypeScript or similar) and want to build and ship software with coding agents.
prerequisites: You can write basic code in Python, JavaScript, TypeScript or a similar language, use the command line and Git, read and explain a short function, and run a simple test. You don't need any experience with coding agents. A laptop with internet access is enough.
syllabus:
- weeks: Weeks 1 to 4
  title: Foundations
  modules:
  - title: 'AI development tools: overview and setup.'
    produce: a working environment and your first agent-made commit.
  - title: Working in a session and in an existing codebase.
    produce: a verified pull request in a repository you didn't write.
  - title: From idea to spec, backlog and full-stack foundation.
    produce: a product brief, a groomed backlog and a minimal full-stack scaffold with passing backend tests.
  - title: Introduction to AI engineering.
    produce: an LLM API app with a chatbot, RAG over documents and a simple tool-calling agent built with coding agents.
- weeks: Weeks 5 to 7
  title: Build and verify
  modules:
  - title: Testing, verification and debugging.
    produce: a test suite, and a seeded bug reproduced, fixed and covered.
  - title: Reviewing agent-generated changes.
    produce: a review record, a reviewer workflow and two automatic checks.
  - title: Containers, CI/CD and deployment.
    produce: your first version deployed through CI (midterm).
  - title: Permissions, sandboxing and safe operation.
    produce: a threat sketch and guardrails for your product.
- weeks: Weeks 8 to 9
  title: Operate and automate
  modules:
  - title: Environments, logs, metrics and an on-call agent.
    produce: dashboards, one alert, and a failure investigated from telemetry.
  - title: 'Reusable workflows: skills, subagents and hooks.'
    produce: packaged implementation and code-review workflows.
  - title: Connecting agents to tools through MCP.
    produce: your product's tools exposed through MCP and used by the agent.
  - title: Agent teams, loops and parallel runs.
    produce: an agent-team backlog batch, automated workflow setup and operating guide.
- weeks: Weeks 10 to 13
  title: Capstone and interviews
  modules:
  - title: Technical interviews and hiring prep (full week, 30 hours).
    produce: algorithm coding drills without AI, a timed take-home, a project presentation and first peer mocks.
  - title: Capstone I and interview practice.
    produce: your 60-hour capstone core alongside weekly coding drills and squad mock interviews.
  - title: Capstone II and interview practice.
    produce: user-tested capstone improvements, mock interviews and project-talk rehearsals.
  - title: 'Capstone III: release, defence and career prep.'
    produce: the launched product, defence, final 30 hours of interview practice and 3 individual 45-min career consultations plus written CV review.
