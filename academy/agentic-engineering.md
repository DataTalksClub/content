overview:
  heading: Why This Program
  paragraphs:
  - More and more job postings ask for experience with AI coding tools, while most material about them is written for beginners. If you already write software, what you need is practice directing agents on real work and checking what they produce.
  - 'The program covers the whole path: from a product idea to a spec and a backlog, through building and reviewing with agents, to deployment, monitoring and teams of agents.'
  - It is full-time and live, and you work on one product that grows every week.
project: You ship a working web application for a real user task. People try it, you improve it from their feedback, and you show how you tested and released each change.
fit_first: You write code today (Python, JavaScript, TypeScript or similar) and want to build and ship software with coding agents.
prerequisites: You can write basic code in Python, JavaScript, TypeScript or a similar language, use the command line and Git, read and explain a short function, and run a simple test. You don't need any experience with coding agents. A laptop with internet access is enough.
syllabus:
- title: Foundations
  modules:
  - week: 1
    title: Set up your AI development tools.
    produce: A working environment and your first agent-made commit.
  - week: 2
    title: Work in a session and in an existing codebase.
    produce: A verified pull request in a repository you didn't write.
  - week: 3
    title: Turn an idea into a spec, a backlog and a full-stack foundation.
    produce: A product brief, a groomed backlog and a minimal full-stack scaffold with passing backend tests.
  - week: 4
    title: Build your first AI application.
    produce: An LLM API app with a chatbot, RAG over documents and a simple tool-calling agent, built with coding agents.
- title: Build and Verify
  modules:
  - week: 5
    title: Test, verify and debug.
    produce: A test suite, and a seeded bug reproduced, fixed and covered.
  - week: 6
    title: Review agent-generated changes.
    produce: A review record, a reviewer workflow and two automatic checks.
  - week: 7
    title: Containerize, deploy and run CI/CD.
    produce: Your first version deployed through CI (midterm).
  - week: 7
    title: Set permissions, sandboxing and guardrails.
    produce: A threat sketch and guardrails for your product.
- title: Operate and Automate
  modules:
  - week: 8
    title: Monitor environments and run an on-call agent.
    produce: Dashboards, one alert, and a failure investigated from telemetry.
  - week: 8
    title: 'Package reusable workflows: skills, subagents and hooks.'
    produce: Packaged implementation and code-review workflows.
  - week: 9
    title: Connect agents to tools through MCP.
    produce: Your product's tools exposed through MCP and used by the agent.
  - week: 9
    title: Run agent teams, loops and parallel runs.
    produce: An agent-team backlog batch, an automated workflow setup and an operating guide.
capstone:
  heading: The Final Project
  modules:
  - week: 10
    title: Build the core of your product.
    produce: The 60-hour core of your final project, tested with real users.
  - week: 11
    title: Release and defend it.
    produce: The launched product with user-tested improvements, and its defense.
